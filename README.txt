THREAD & CO. CLOTHING WEBSITE

How to use:
1. Open this folder in Visual Studio Code.
2. Open index.html in your browser.
3. Edit the brand name, prices, products, contact information and text.
4. Replace the sample product image areas with your actual product photos.
5. When ready, publish the files using a web hosting service.

Files:
- index.html = website structure
- style.css = design and layout
- script.js = basic interactive features

Important:
This is a front-end starter website. The cart and newsletter are demonstration features only.
For real online orders, payments, customer accounts, inventory and order management, you'll need a backend or an e-commerce service.
